# T-5 Agent foundation
Trusted registry, bounded structured plan, A0 plan-only and A1 scoped execution, deny by default, L3/L4 approval plus explicit grant, sequential execution and cooperative STOP. CLI registers only pure text tools. No shell, filesystem, network, external side effects or model-generated plans enabled. Approval callback is a trusted dependency, not a real UI; grants are session configuration, not a durable authority. Completed-step evidence is in memory only, not durable recovery. No self-evaluation model or natural language intent planner yet. No automatic retry or resume. No real user data in tests. Run npm run agent:local -- "halo mio" (arguments may be saved in shell history).
