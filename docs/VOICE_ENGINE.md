# T-8 voice foundation
Injected STT/TTS functions, explicit caller consent, ID/EN language selection, bounded input, PCM RMS energy threshold, Logical CORE states, cooperative abort and suppression of late output. No devices, model downloads, actual synthesis, voice identity sample, recording, playback or cloud service. Consent is caller-provided, not trusted UI authorization. Adapters must be trusted and cooperate with cancellation; STOP cannot guarantee interruption of noncooperative audio playback. dispose lifecycle and cross-engine concurrency need hardening. Personality styles and user-reported mood only; no emotion inference. Tests use synthetic PCM and mock adapters. Windows and CI pending.
