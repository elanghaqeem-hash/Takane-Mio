# T-1 desktop foundation
Electron 45.3.4 pinned at direct dependency level; lockfile and supply chain audit pending. Node 24 target. Run npm install then npm start on a test host only. Minimal vanilla renderer is a deliberate bootstrap before React/TS/Vite. No model or network operations exposed. IPC exact sender and main frame checks, deny permissions and popups, no Node integration, CSP. STOP is session-local and cooperative; no persistent latch or external process termination. Core display is a placeholder sphere, not a galaxy or knowledge visualization. Installer packaging, signing, Windows UI smoke test, integration tests and dependency lockfile remain pending.
