# T-19.10.08 Offline intelligence transport

`createOfflineTransport` restricts requests to exact provider-specific IPv4 loopback GET inventory and POST chat endpoints. Request redirects are disabled, credentials omitted, pre-aborted requests blocked, and redirected responses rejected. This is an application transport guard, not a network sandbox. A trusted fetch implementation and local server can still communicate externally. No proof of process identity, offline inference, proxy absence, or model availability is supplied.
