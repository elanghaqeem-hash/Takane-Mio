# T-0.04 security baseline
Deny by default, scoped purpose and expiry, explicit L3/L4, deny L5. New execution gate invokes a trusted policy callback and passes an AbortSignal; no renderer or model may supply policy or arbitrary handlers. STOP is latched for an instance; abort is cooperative and cannot undo completed side effects or kill a noncooperative process. No OS tool is wired. Future trusted service registry, schema validation, grant authority, audit logging, sandbox, process termination and IPC binding remain mandatory. Do not enable privileged tools until integration tests pass.
