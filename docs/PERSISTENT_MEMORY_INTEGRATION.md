# T-19.10.09.03 Persistent memory integration

AssistantRuntime(config,{persistentMemory}) accepts an operator-provisioned store implementing remember/search/forget/close, intended for EncryptedMemoryStore. The runtime owns the injected store and closes it on terminal stop. Explicit consent is required for each remember/recall/forget call. Normal chat and clear do not read, write, or delete persistent records. Recall returns data to the caller, never automatically injects it into model instructions. The injected store is trusted; the interface itself does not enforce encryption. Configure a 32-byte key from a trusted local key management process and reopen the same encrypted database with the same key after restart. Do not log keys. No automatic migration from plaintext stores. Tests added for restart persistence, consent, deletion, missing store, and ordinary chat isolation; execution not verified in this session. Requires Node.js with node:sqlite. Windows key custody, UI, full regression and real inference remain pending. No deployment change.
