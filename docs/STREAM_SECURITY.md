# T-19.08.01 stream resource hardening
Before fetch, reject aborted signals. Cap bytes read at 2 MiB and parsed lines at 16384 (including blank and ignored SSE lines), retain the 256000 UTF-16 buffered frame and 64000 output limits. These conservative caps can reject legitimate large or highly fragmented responses. Data already buffered by network transport is outside the application cap; cancellation is cooperative and server identity/offline isolation are not proven. Five new tests and five existing inference challenge tests passed on Node 22.16 Linux with injected HTTP streams. No actual model, Windows, Electron or full CI tested. No cloud deployment changes.
