# T-16 orchestration foundation
Trusted static registration (64 tools max), sequential workflows (16 steps max), prior output handoff, defensive cloning, L0-L2 only, scoped grant check, in-memory HMAC audit, runtime health and cooperative STOP. Five local tests on Node 22.16.0 Linux use synthetic tool functions and actual security/core primitives. No production tool binding, desktop runtime, scheduler, OS sandbox, persistence or end-to-end model integration. No high-risk execution. Trusted host must bound tool input/output and resource consumption; noncooperative tasks cannot be forcibly interrupted. Grant revocation prevents future steps, not necessarily already running tasks.
