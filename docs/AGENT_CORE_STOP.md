# T-19.08.05 Agent CORE STOP propagation
AgentEngine subscribes to its shared CoreState during execution and stops its ExecutionGate when that state stops. It checks state before accepting a tool result and removes the listener in finally. Three local tests passed on Node 22.16 Linux using simulated tools and actual CoreState/gate/policy. Includes stop in active handler, stop on transition, and repeated normal executions. No full regression, actual model, Windows or Electron test. Cancellation remains cooperative; unresolved approval callbacks and non-cooperative tools may not terminate, completed effects cannot be undone, independent CORE instances are not connected, and persistent audit and sandbox remain pending. No deployment changes.
