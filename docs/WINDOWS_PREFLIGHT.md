# T-19.02 Windows development host preflight
Run npm run windows:preflight. Checks Windows, x64/arm64 architecture, Node 24+, package-lock.json presence, installed Electron exe presence and 2 GiB free disk on repo volume. Disk limit is a provisional development prerequisite excluding model weights. Presence does not prove lock integrity, binary trust, runtime compatibility or installer readiness; arm64 is not yet tested. CLI and Windows not yet exercised; four pure evaluator tests passed Linux Node 22.16.0. Before packaging, generate/review dependency lock on trusted host, npm ci, verify:suite, start Electron, test local model and STOP. No installer artifact generated. No cloud change.
