# T-4 Memory foundation
Node built-in SQLite, schema 1, explicit consent required for CLI writes; no automatic capture. Session memory is volatile and bounded. Persistent episodic and semantic types are labels, not embeddings. Search is literal substring matching, not semantic/vector retrieval. Galaxy returns only authorized indexed ID/cluster metadata. SQLite secure_delete is best effort, not forensic erasure; backups and filesystem layers can retain copies. Data is not encrypted by this code. CLI stores data under ~/.mio/memory.sqlite; avoid sensitive data until encryption, permissions and audit controls are verified. CLI arguments may appear in shell history. Desktop provider intentionally remains empty until app data path and consent boundary integration are validated. No full backup or inference retrieval integration yet.
