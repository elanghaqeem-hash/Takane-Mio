# T-3 local runtime
CLI only; Ollama default loopback 11434 and llama.cpp server loopback 8080. No cloud fallback, redirect denied, explicit user model selection, streaming NDJSON/SSE, bounded context/output, cancellation. No model bundled, downloaded or verified. Run npm run chat:local -- ollama MODEL "Halo MIO" after installing and running Ollama and selecting an installed model. For llama.cpp use llamacpp and configured served model. OpenRouter intentionally not implemented yet. Local service authentication, process management, desktop streaming IPC and benchmark remain pending. Mock tests do not prove inference.
