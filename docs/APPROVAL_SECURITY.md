# T-19.08.02 approval boundary
ApprovalVault holds one private cloned plan with UUID and a 60-second monotonic deadline. Replacement, clear and STOP invalidate pending plans; rollback or invalid clock permanently stops the vault. Display expiresAt uses wall time for compatibility only. AssistantRuntime and ReviewedSession use the shared primitive. Five vault tests passed Node 22.16 Linux.
