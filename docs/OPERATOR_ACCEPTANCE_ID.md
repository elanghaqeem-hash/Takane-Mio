# Checklist penerimaan panduan (belum dilaksanakan)
Catat commit, OS, arsitektur, Node, Electron, model, tanggal, hasil, referensi bukti dan reviewer independen. Jangan simpan API key atau data pribadi.
- [ ] Checkout bersih, dependensi dan lockfile direview.
- [ ] Linux dan Windows Node 24 full regression lulus.
- [ ] Windows preflight dan desktop smoke lulus.
- [ ] Model probe, inference aktual, offline isolation lulus.
- [ ] Knowledge opt-in, data sintetis, penghapusan, STOP diuji.
- [ ] Installer/portable build dan validasi keamanan.
- [ ] Recovery drill lengkap pada lingkungan terpisah.
- [ ] Web HTTP dan browser smoke, jika ruang lingkup rilis mencakup web.
- [ ] Reviewer mengeksekusi panduan instalasi dan operasi tanpa bantuan penulis.
Semua item belum memiliki bukti acceptance pada tahap ini.
