# T-18 unified assistant runtime
Integrates real core, local router/adapter, session memory, strict planner, safe tool registry and AgentEngine. Only text.words and text.length at L0. Approval is caller-provided, tied to an internally retained one-use plan ID with 60-second expiry; no trusted desktop approval UI. One concurrent task; stop aborts cooperative requests and clears RAM history. No persistent memory or model verification. Six local integration tests on Linux Node 22.16.0, including actual HTTP loopback to a simulated Ollama endpoint. Port 11434 must be free for that test; do not run against a live model server. No llama.cpp live test, Windows, full suite, build, deployment or recovery drill. Release blocked pending these gates.
