# T-18.04 automation foundation
Process-local manual tick scheduler; one-shot and fixed-delay recurring tasks; dependencies on earlier one-shot jobs; maximum 100 tasks and 1000 history entries. Uses existing GrantAuthority/ExecutionGate and actual L0 text tools, reauthorizes each run. No external actions, model-generated jobs, background timer, durable storage, retry, event connector or desktop integration. Failed/denied tasks require manual recreation with a new ID. STOP is cooperative. History excludes task text and results. Tests included; execution evidence recorded separately.
