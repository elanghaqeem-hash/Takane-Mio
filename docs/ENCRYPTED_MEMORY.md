# T-19.08.04 experimental encrypted memory
Separate schema 2 SQLite file, explicit create flag exclusive file creation, AES-256-GCM random nonce and authenticated record ID, encrypted content/cluster/kind/timestamp, caller-supplied 32-byte key, max 1000 records and 16000 UTF-16 units content. Consent flag required for write/search/delete. Five temporary SQLite tests passed Node 22.16 Linux; no plaintext synthetic content/cluster in sampled database file. IDs/count/size remain visible. No database-wide integrity or rollback detection, key verification before write (wrong key can open and append; do not use for real data), secure key custody, guaranteed deletion, OS isolation or authenticated consent. Search decrypts all bounded rows in RAM. Existing schema 1 unchanged and plaintext; no migration, desktop/galaxy integration or external backup. Not production-ready. No deployment changes.
