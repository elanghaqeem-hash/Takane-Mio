# T-18.03 local assistant runtime
Combines actual LocalRouter/adapter, SessionMemory, CoreState and AgentEngine. Chat and plan modes are separate; plans use single-use 60-second approval and only internal text tools. STOP cancels the current request and clears session memory. This runtime implements its own review lifecycle rather than wrapping ReviewedSession; consolidation pending. Six new tests and four prior session tests ran in Linux; real HTTP loopback used a simulated Ollama endpoint, not a real model. No desktop IPC, persistent history, endpoint authentication or live inference verified. Test binds port 11434; run only in an isolated environment with that port free. No paid API required.
