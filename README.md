# Takane-Mio
Independent local-first personal AI agent with Galaxy Core, native model routing, multimodal intelligence, creative engines, and secure disaster recovery architecture.

## Project Regenesis
Development baseline on `regenesis/t0-foundation`. Not a working AI yet. Run `npm test` with Node.js 24. See architecture and recovery docs. No external AI credentials are required by this foundation.

## Desktop bootstrap
Node.js 24 required. `npm install` then `npm start` on a test host; dependency lock and Windows launch validation are pending. `npm run diagnostics`, `npm run check`, `npm test` do not require Electron installation. No AI inference is available yet.
