# Architecture baseline — T-0
Windows-first Electron/React/TypeScript/Vite renderer, sandboxed preload, typed IPC, local authenticated loopback gateway, native router, local model adapters. SQLite and local retrieval. Ollama or llama.cpp candidates; OpenRouter off by default; no direct cloud API requirement. No privileged operation from model or renderer. S15 security gates S06 agent tools. Core/visual state separated; Galaxy indexes actual authorized records only. Creative studios share document kernel, asset registry and render queue. S16 health and S20 recovery isolate failures. Default autonomy A1. Phased delivery: V1 functional local AI before advanced visuals and creative studios. Architecture is proposed, not validated on target hardware.
